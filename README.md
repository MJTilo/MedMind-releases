# MedMind for Android

[Download the latest APK](https://github.com/MJTilo/MedMind-releases/releases/latest)

Open the APK on Android and follow the installation prompt. Future updates are available in **Settings → App updates**.

## Current release: v1.0.40

[Download MedMind v1.0.40](https://github.com/MJTilo/MedMind-releases/releases/download/v1.0.40/MedMind-v1.0.40.apk)

- Clearer schedule-start selection and no automatic scrolling when a medication entry is incomplete.
- Request deadlines and recovery messages, with entered prescription details retained after failed saves.
- Complete fresh-database setup and automated verification.

Built from [Shonome/CapstoneMedmind v1.0.40](https://github.com/Shonome/CapstoneMedmind/releases/tag/v1.0.40).

## Dose confirmations

The dose confirmation button turns gray and becomes disabled 61 minutes after the scheduled time. The dose remains marked as missed in the caregiver adherence summary unless a taken confirmation was recorded within the allowed window.
